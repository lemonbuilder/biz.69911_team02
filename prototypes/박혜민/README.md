# Facilitator

대화가 깊어질 수 있도록, 더 진솔한 나를 나눌 수 있도록, 서로를 더 잘 알아갈 수 있도록 질문을 던집니다.
이 질문에 답하는 것으로 대화를 시작할 수 있습니다. 원하지 않으면 그냥 편하게 대화하셔도 돼요.

- 첫 질문은 가볍게 시작합니다. 불리고 싶은 이름과 함께 한 사람씩 돌아가며 답해 보세요.
- 대화가 끊기면 "다음 질문"을 누르세요. 나눈 이야기에 맞춰, 세 사람 모두 답할 수 있는 질문을 건넵니다.
- 가벼움 · 중간 · 깊음 중 얼마나 깊이 들어갈지는 여러분이 정합니다. 언제든 되돌릴 수 있어요.
- 답하고 싶은 만큼만 답하세요. 넘기고 싶은 질문은 "이 질문 넘기기"를 누르면 됩니다.
- 앱은 먼저 끼어들지 않습니다. 질문은 앱이 건네지만, 대화는 여러분의 것입니다.
- 대화를 듣는 것은 세 사람이 모두 동의했을 때만입니다. 언제든 "듣기 멈춤"을 누를 수 있고, 모임을 끝내면 이 기기의 기록을 지웁니다.

## 현재 상태 (2026-10-28)

- API 키는 향후 발급 예정입니다. 지금은 키 없이 고정 질문으로 전체 흐름이 동작합니다.
- 마이크 받아 적기는 미해결입니다. 말소리 감지까지는 되지만, Chrome 서버 인식이 결과를 돌려주지 않습니다. 자세한 내용은 spec의 「테스트 결과」를 보세요.

## 실행

```bash
cd prototypes/박혜민
npm install
cp .env.example .env   # ANTHROPIC_API_KEY 채우기 (비워 두면 고정 질문만)
npm start              # http://localhost:3100
```

- **Chrome**에서 **`http://localhost:3100`**으로 엽니다. 마이크는 localhost나 HTTPS에서만 켜지고, 음성 인식(Web Speech API)은 Chrome에서 동작합니다.
- **키가 없어도 됩니다.** 첫 질문과 단계별 고정 질문으로 전체 흐름이 돌아가고, 화면 아래에 "기본 질문"이 표시됩니다.

| 조건 | 질문 |
|---|---|
| 모임 시작 | 아이스브레이킹 고정 세트 (AI 사용 안 함) |
| 마이크 켜짐 + 직전 3분에 30자 이상 받아 적음 + 키 있음 | Claude Haiku 5.5가 대화에 맞춰 생성 |
| 그 밖의 경우, 또는 5초 안에 답이 없거나 답이 문장 규칙을 어김 | 현재 단계의 고정 질문 |

## 사용 흐름

1. 동의 화면에서 세 사람이 각자 체크하고 "시작". 원하지 않으면 "마이크 없이 시작".
2. 첫 질문에 돌아가며 답한다.
3. 대화가 끊기면 "다음 질문", 질문이 마음에 안 들면 "이 질문 넘기기".
4. [가벼움 | 중간 | 깊음]을 눌러 단계를 오르내린다.
5. "듣기 멈춤"을 누르면 마이크가 꺼지고 받아 적은 글이 지워진다. "다시 듣기"는 세 명이 다시 동의해야 한다.
6. "모임 끝내기" → 확인 → 이 기기의 기록 삭제.

`D` 키: 테스트용 숫자(재시작 횟수, 분당 받아 적은 글자 수). 받아 적은 원문은 어디에도 보여 주지 않습니다.
개발자 도구 콘솔에서 `facilitatorDebug()`로 버퍼 길이와 듣기 상태를 볼 수 있습니다.

## 구조

- `server.js` — 정적 파일과 `/api/question`. 받은 대화는 Claude에 전달만 하고 저장·로그하지 않음
- `lib/question.js` — 프롬프트, Claude 호출(4.5초 제한), 답 검사(한 문장·60자·물음표)
- `public/questions.js` — 아이스브레이킹과 단계별 고정 질문
- `public/app.js` — 동의, 받아 적기와 자동 재시작, 3분 버퍼, 질문 흐름, 삭제
- `npm test` — 키 없는 경로, 입력 검사, 답 검사, 고정 질문 기준 자동 테스트
