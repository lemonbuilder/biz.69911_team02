# 역할 돌리기

서로 다른 생각이 오가도록, 세 사람이 대화 속 역할을 돌아가며 맡습니다.

- 말 꺼내기 · 되짚기 · 다르게 보기, 세 역할이 한 차례마다 한 칸씩 돕니다.
- 이야기 하나가 일단락되면 "다음 차례"를 눌러 주세요.
- 역할이 버거우면 "이번엔 쉬어요"를, 역할 없이 이야기하고 싶으면 "역할 없이 계속"을 누르면 됩니다.
- 이 화면은 대화를 듣지도, 기록하지도 않습니다.

> 이기거나 설득하려는 자리가 아니에요. 서로 다른 생각을 발견하려는 자리예요.
> 처음 만난 사람과의 깊은 대화는 생각보다 덜 어색하고, 상대는 생각보다 내 이야기에 관심이 있다고 해요.
> 조언은 부탁받았을 때만 해 주세요.

진짜대화 Team 02 · 문피아 프로토타입 · 스펙: [`docs/specs/문피아-role-rotation.md`](../../docs/specs/문피아-role-rotation.md)

## 실행

`public/index.html`을 Chrome에서 바로 열면 됩니다. 설치할 것도, API 키도 없습니다.

팀원 프로토타입(3000, 3100)과 나란히 띄우고 싶으면:

```bash
cd prototypes/문피아
npm start              # http://localhost:3300
```

## 세 역할

| 역할 | 화면 설명 |
|---|---|
| 말 꺼내기 | 지금 이야기에 대한 내 생각이나 경험을 먼저 꺼내 주세요. 들은 이야기나 가벼운 경험이어도 괜찮아요. |
| 되짚기 | 방금 들은 말을 한 문장으로 되짚고 '이렇게 이해했는데 맞아요?' 하고 확인한 뒤, 궁금한 걸 하나 더 물어봐 주세요. |
| 다르게 보기 | 다른 경우나 다른 시선이 떠오르면 하나 꺼내 주세요. 반대하라는 뜻은 아니에요. 떠오르지 않으면 '저도 비슷해요'도 괜찮아요. |

화두는 실패(기본) · 잘 산다는 것 · 어른 · 운과 노력 · 화두 없이 중에서 시작할 때 고릅니다. 문구와 연구 근거는 spec과 [`RESEARCH.md`](RESEARCH.md)에 있습니다.

## 사용 흐름

1. 노트북을 테이블 한쪽 끝에 두고, 세 사람이 화면을 바라보며 반원으로 앉는다. 오늘의 화두를 고르고, 부를 이름은 적어도 되고 비워도 된다.
2. 첫 인사가 끝나면 "역할 시작". 화면 위에 화두가 한 줄로 뜨고, 처음 배정은 무작위.
3. 이야기 하나가 일단락되면 누구든 "다음 차례". 모두 한 칸씩 같은 방향으로 옮겨 가서, 세 차례면 모두가 세 역할을 한 번씩 맡는다.
4. 역할이 버거우면 자기 칸의 "이번엔 쉬어요". 그 차례 동안만 비워 두고, 다른 사람과 바꾸지 않는다.
5. "역할 없이 계속" → 역할 칸이 사라진다. "역할 다시 켜기"로 멈췄던 배정에서 이어 간다.
6. "끝내기" → 입력한 이름을 지우고 끝 화면.

## 구조

- `public/rotation.js` — 순환 규칙(첫 배정, 한 칸 이동, 쉬기), 역할 문구, 화두 목록. 화면과 분리된 순수 함수
- `RESEARCH.md` — 설계 결정별 연구 근거 (1차 출처 확인, 2026-10-30)
- `public/app.js` — 화면. 상태는 메모리에만 두고, 저장·네트워크·마이크를 쓰지 않는다
- `serve.js` — 의존성 없는 정적 서버 (포트 3300)
- `npm test` — 순환 규칙, 역할 문구, 저장·네트워크·마이크를 쓰지 않는지 자동 검사. 직접 해 볼 테스트를 대신하지 않는다
