# WhyTree — 정직한

- 날짜: 2026-10-28
- 위로 갈수록 why, 아래로 갈수록 how. 각 항목은 위 항목의 how입니다.
- `(점선)` = 부가적인 why로 연결된 how (같은 상자가 실선으로 다른 why에도 연결됨)

```
더 나은 인간 되기
  온전한 소통
    생각하는 속도와 대화 속도의 일치
      말하는 속도 조절
      생각의 속도 조절
      3명의 대화 (점선)
    대화에 집중
      3명의 대화
      스마트폰 꺼두기
      두 명이서 대화
  인간적 성장
    장기에 걸친 정기적 대화
      3명의 대화
      온/오프라인 정기 모임
    자기 회고
      3명의 대화 (점선)
```
